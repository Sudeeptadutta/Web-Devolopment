CSS

CSS stands for Cascading Style Sheets, and it is the standard language used to style and design the visual layout of web pages. While HTML builds the structure of a website (like text, paragraphs, and buttons), CSS controls how that structure actually looks to the user. Together with HTML and JavaScript, it is a cornerstone technology of the World Wide Web.

HTML

HTML stands for HyperText Markup Language and it is the standard language used to create and structure everything you see on the web. It acts as the "skeleton" or blueprint of a webpage, telling your web browser how to display text, images, links, and multimedia.s
